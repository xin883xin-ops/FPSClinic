服務條款

KitLab 商店（kitlab.store）由 KitLab 官方經營，提供各種技能包：有付費的服務（例如遊戲效能遠端優化、30 分鐘一頁式網頁），也有免費的工具（例如精選站點啟動台 KitLab Dash）。

每個技能以自己的頁面為準

價格、內容、保固、修改次數與退費條件，寫在各技能自己的頁面上。本頁是共通的原則；兩者不一樣時，以該技能頁面的寫法為準，但不會比本頁的「退款與爭議」更不利於你。

下單與付款

  • 目前透過 LINE 洽詢、確認內容後才開始；確認之前不會收費。

我們不接的案子

隱私權

我們盡量少拿你的資料。目前的情況是：

網站本身

  • 不需要註冊或登入，雲端同步也一樣。
  • 不放追蹤工具、不放廣告 cookie，也不做訪客分析。
  • 網站放在 GitHub Pages，網域與連線經過 Cloudflare，字型來自 Google Fonts。這些服務會依它們自己的政策留下一般的連線紀錄（例如 IP 位址、瀏覽器類型），我們不會另外取得或使用這些紀錄。

精選站點啟動台 KitLab Dash 與應用商店

  • 你放進 Dock 的站點、從商店安裝的應用、看過哪一期更新，只存在你自己裝置的瀏覽器裡，我們看不到。清除瀏覽器資料就會一起清掉。
  • 商店的應用目錄由我們的伺服器（Cloudflare Workers）提供。讀取目錄不需要任何身分，我們不記錄誰看了或裝了哪個應用。
  • 其他開發者的應用圖示透過 Google 的網站圖示服務載入，Google 會依它的政策留下一般連線紀錄。
  • 點「前往官方網站」會開到對方的網站，之後就適用對方的隱私權政策。

建議新站點、回報問題

  • 你在 Dash 或商店送出的建議與回報，會存進我們在 Cloudflare 的資料庫，內容只有你寫的文字、網址與相關應用名稱。
  • 為了擋洗版，我們只保存你 IP 位址的雜湊值（無法反推回 IP），不保存 IP 本身。處理完的回報 180 天後自動刪除。

加密雲端同步（自己選擇開啟）

  • 預設關閉。你按下開啟並勾選同意後，Toolkit 工具箱的捷徑、待辦、便條與外觀設定，以及 Dash 的 Dock 和已安裝的應用，才會同步到雲端。
  • 資料在你的裝置上用 AES-256 加密後才上傳。加密金鑰由只有你拿得到的復原碼推導而來，復原碼不會傳給我們，所以我們看不到內容，也無法幫你解開。
  • 不需要帳號、Email 或手機號碼。我們只存加密後的資料、由復原碼推導的編號，以及一組權杖的雜湊值。
  • 復原碼弄丟就無法還原，請自行妥善保存，也不要交給別人；拿到復原碼的人就能讀取並修改你的同步資料。
  • 你可以隨時在「雲端同步」裡停止同步，或刪除雲端資料。超過 400 天沒有更新的雲端資料會自動刪除。

你用 LINE 聯絡我們時

  • 不會賣給或提供給第三方。
  • 想要我們刪除你的資料，用 LINE 說一聲就好。
