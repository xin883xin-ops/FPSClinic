驅動檢查・備份・還原

不用下載任何軟體。複製一段指令到 Windows 執行，就能看出哪些裝置缺驅動、去哪裡下載官方版本；裝好之後，再用一行指令把整套驅動備份起來，重灌完一鍵裝回。

檢查用的指令只讀取，不安裝、不修改 貼上的資料只在你的瀏覽器分析，不會上傳 只連到原廠與微軟官方，不提供來路不明的檔案
01

打開 PowerShell

按 Win + X，選「終端機」或「Windows PowerShell」。這一步不需要系統管理員。

02

複製這段指令，貼上後按 Enter

PowerShell · 一般權限

      

      
這段指令在做什麼？
        
    
          
  • Win32_ComputerSystem讀電腦品牌與型號，例如 HP ProBook 450 G8。
    • 
          
  • Win32_BaseBoard讀主機板廠牌與型號，組裝電腦要靠這個找驅動。
    • 
          
  • Win32_OperatingSystem讀 Windows 版本，例如 Windows 11 23H2。
    • 
          
  • Win32_PnPEntity讀裝置清單，只挑出有問題的裝置，以及顯示卡、網卡、音效、藍牙、相機。
    • 
          
  • Set-Clipboard把結果複製到剪貼簿，方便你貼回來。不會傳到任何地方。
    • 
        

        
不會讀取序號、帳號、檔案或網路紀錄。

02
用系統管理員開 PowerShell，貼上這段

      
按 Win + X，選「終端機（系統管理員）」，跳出確認視窗按「是」。匯出驅動需要這個權限。

      

        
PowerShell · 系統管理員

        

      

      
這段指令在做什麼？
        
    
          
  • pnputil /export-driver *Windows 內建的工具，匯出所有另外安裝的驅動（顯示卡、網卡、音效、藍牙等）。Windows 本來就有的驅動不會匯出，所以檔案不會太大。
    • 
          
  • Get-WindowsDriver另外存一份 driver-list.csv，記下每個驅動的廠商、版本和日期。
    • 
          
  • Compress-Archive打包成一個 zip，方便搬移和保存。
    • 
        

      

    

    
備份檔只存在你的電腦上，KitLab 不保存、也看不到。建議複製一份到隨身碟，或放進你自己的 Google Drive、OneDrive。

    
這份備份只適合裝回同一台電腦，或同型號的電腦。換了不同的機器，請回到「檢查驅動」找對應的版本。

  


  
  

    

      
01
先把備份的 zip 解壓縮

      
在 zip 上按右鍵 →「解壓縮全部」。解壓縮後的資料夾路徑貼到下面，例如 E:\DriverBackup-20261018。

      
      
    

    

      
02
用系統管理員開 PowerShell，貼上這段

      

        
PowerShell · 系統管理員

        

      

      
pnputil /add-driver … /subdirs /install 會把資料夾裡所有驅動加進 Windows 並安裝到對應的裝置。跑完建議重新開機。

    

    

      
03
重開機後再檢查一次

      
回到「檢查驅動」再跑一次。如果還有裝置缺驅動，那通常是備份時就沒有的，照建議的連結補裝即可。
