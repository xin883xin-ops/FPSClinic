常見問題

客人需要下載 App 嗎？

不用。用手機相機掃 QR Code，就會打開留言頁面。

我需要有網站或粉絲專頁嗎？

不需要。語音名片就是為沒有網站的人設計的。

一定要重印名片嗎？

要把 QR Code 印上去，所以需要印一次。如果你剛好要補印名片，順便加上去就好。

QR Code 要印多大？

建議至少 2 × 2 公分，四周留一點白邊。深色的碼印在淺色的底上最好掃。送印前先用手機掃一次確認。

留言會寄到哪裡？

寄到你設定的 Email。

以後我想換功能或改內容，要重印嗎？

不用。QR Code 連到 KitLab 的固定網址，內容由我們後台調整，印好的名片都可以繼續用。

試用期結束後，名片會不會失效？

不會變成錯誤頁面。沒有續用的話，掃碼會顯示基本的聯絡頁面。

留言的內容安全嗎？

留言是給名片主人聽的。留言預設保存 30 天，每天自動刪除過期的。我們只存 IP 的雜湊值，不存原始 IP。只有名片主人用專屬的私人連結才聽得到。
